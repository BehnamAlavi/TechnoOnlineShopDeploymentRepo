# TechnoShopOnlineDeploymentRepo

Production-ready deployment configuration for TechnoShop Online application with Docker Compose, GitHub Actions CI/CD, and GHCR container registry.

## 📋 Repository Structure

```
TechnoOnlineShopDeploymentRepo/
├── docker-compose.yml          # Production Docker Compose configuration
├── nginx.conf                  # Nginx reverse proxy configuration
├── init.sql                    # Database initialization (or backup.text)
├── .env.example                # Environment variables template
├── .gitignore                  # Git ignore rules
├── .github/
│   └── workflows/
│       └── deploy.yml          # GitHub Actions CI/CD pipeline
├── scripts/
│   ├── setup-ssh.sh            # SSH key generation

```

## 📦 Prerequisites

### GitHub Secrets Required

Set these in repository Settings → Secrets and variables → Actions:

| Secret | Description | Example |
|--------|-------------|---------|
| `VPS_HOST` | VPS IP address | `5.160.219.141` |
| `VPS_USER` | SSH username | `behi` |
| `VPS_PORT` | SSH port | `22` |
| `VPS_SSH_KEY` | SSH private key (ed25519) | (multiline key) |
| `POSTGRES_PASSWORD` | PostgreSQL password | (secure password) |
| `GITHUB_TOKEN` | (Auto-generated by GitHub) | (auto) |

### VPS Prerequisites

1. **Docker installed** and user in docker group
2. **Docker Compose** installed
3. **SSH key-based authentication** configured
4. **Application directory**: `/opt/techno-shop`

## 🔧 Initial Setup

### 1. Generate SSH Key (Local Machine)

```bash
bash scripts/setup-ssh.sh
cat ~/.ssh/deploy_key  # Copy contents for GitHub secret
```

### 2. Setup VPS Environment (One-time)

```bash
# SSH to VPS and run
ssh behi@5.160.219.141
bash -c "$(curl -fsSL https://raw.githubusercontent.com/your-username/TechnoOnlineShopDeploymentRepo/main/scripts/vps-setup.sh)"
```

Or manually:
```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
mkdir -p /opt/techno-shop ~/.ssh
```

### 3. Add GitHub Secrets

Go to repository **Settings → Secrets and variables → Actions** and add:

```
VPS_HOST=5.160.219.141
VPS_USER=behi
VPS_PORT=22
VPS_SSH_KEY=(paste private key from setup-ssh.sh)
POSTGRES_PASSWORD=(secure password)
```

## 🚀 Deployment

```bash

```

## 🔄 Updating Service Versions

To deploy a new version (e.g., v1.1.0):

1. Update `docker-compose.yml`:
   ```yaml
   techno-api-service:
     image: ghcr.io/owner/techno-api:${TECHNO_API_VERSION:-1.1.0}
   ```

2. Update `.github/workflows/deploy.yml`:
   ```yaml
   echo "techno-api=${{ env.REGISTRY }}/$REPO_OWNER/$REPO_NAME/techno-api:1.1.0" >> $GITHUB_OUTPUT
   ```

3. Push changes
   ```bash
   git add .
   git commit -m "Bump versions to 1.1.0"
   git push origin main
   ```

## 🛠️ Troubleshooting

### Container won't start
```bash
docker compose logs techno-api
docker compose ps
```

### Port conflicts
```bash
sudo lsof -i :3000
sudo lsof -i :5001
```

### Database connection error
```bash
docker compose exec postgres pg_isready
docker compose logs postgres
```

### GHCR authentication failed
```bash
docker logout ghcr.io
echo "TOKEN" | docker login -u USERNAME --password-stdin ghcr.io
docker compose pull
```

### Disk space issues
```bash
docker system df
docker system prune -a
```
